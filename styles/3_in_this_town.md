# 🏘️ In this town

**Rendu** : mini-série dans une ville 3D, personnages et décors type Roblox.

**Outils (gratuits)** : Roblox Studio, Blender, Sketchfab (**assets gratuits / téléchargeables uniquement**), ffmpeg.

**Workflow** : construire/choisir la ville → placer les personnages → caméra → rendu → montage.

**Conseils** : vérifier la licence de chaque asset Sketchfab (CC0 / CC-BY avec crédit).
