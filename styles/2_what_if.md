# ❓ What if…

**Rendu** : scénarios hypothétiques (« Et si… »), visuels explicatifs + infographies animées.

**Outils (gratuits)** : Remotion ou HyperFrames, ffmpeg, Blender (optionnel), assets libres.

**Workflow** : question d'accroche → conséquences par paliers → chute finale.

**Conseils** : accroche dans les 3 premières secondes, escalade progressive.
