# 🧍 Stickman story

**Rendu** : personnages bâtons, fond simple, narration dynamique.

**Outils (gratuits)** : Remotion ou HyperFrames, ffmpeg, sons libres.

**Workflow** : script → voix off → scènes 2D animées → SFX → export.

**Conseils** : rythme rapide, 1 idée par scène, texte à l'écran limité.
