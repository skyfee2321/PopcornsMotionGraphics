# 🍿 Popcorn's MotionGraphics

Un **skill** complet à installer pour créer des **motion graphics avec l'IA** — un simple dossier + un prompt, et votre IA devient votre studio de motion design.

---

## 📦 Installation

### Option 1 — Téléchargement via Git (recommandé)

```bash
# 1. Cloner le dépôt
 git clone https://github.com/skyfee2321/Popcorn-s-MotionGraphics.git

# 2. Extraire le contenu dans le dossier de votre choix
#    (dézippez / copiez le dossier "skill" à l'endroit voulu)

# 3. Ouvrez le dossier dans votre outil IA préféré
#    (Claude, Cursor, VS Code + Copilot, etc.)
```

Puis lancez simplement le prompt du skill (voir `SKILL.md` / `prompt.md` à la racine du dossier) :

> 🎬 *"Crée-moi un motion graphic sur..."*

### Option 2 — Téléchargement ZIP

1. Cliquez sur le bouton vert **Code → Download ZIP**
2. Dézippez l'archive
3. Copiez le dossier extrait où vous voulez
4. Ouvrez-le avec votre IA et lancez le prompt

---

## 🧠 Utilisation (mode Skill)

Le dossier contient :

| Fichier | Rôle |
|---|---|
| `SKILL.md` | Le prompt système du skill — copiez-le dans les instructions de votre IA |
| `templates/` | Exemples de prompts prêts à l'emploi |
| `assets/` | Ressources (sons, overlays, LUTs...) |

**Étapes :**
1. Ouvrez votre projet IA
2. Collez le contenu de `SKILL.md` dans les instructions système (ou importez le dossier comme skill)
3. Demandez : *"Génère un motion graphic de [sujet] en [durée], style [cinématique / cartoon / corporate]"*

---

## ✨ Exemples de prompts

```
"Motion graphic d'intro YouTube, 10s, style néon cyberpunk, musique énergique"
"Animation de texte pour une pub produit, 15s, minimaliste, fond blanc"
"Explainer vidéo animé sur [concept], 30s, style flat design"
```
