# Instructions for any AI / agent

This repository is a motion graphics **skill**. Read and follow `SKILL.md` exactly.

- Trigger: `/popcornM`
- Style sheets: `styles/`
- Tool installation: `guides/INSTALLATION.md`
- If you can't perform an action, use the "🛠️ YOUR TURN" format described in `SKILL.md`.
- Reply in the user's language.

## Using this skill without file access (ChatGPT, Gemini, etc.)
The user pastes the content of `SKILL.md` into the custom instructions (or at the start of the conversation), then types `/popcornM`. When a style sheet or guide is needed, ask the user to paste the matching file.
