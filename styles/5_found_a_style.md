# 🎨 Found a style

**Principe** : l'utilisateur fournit une référence (lien, vidéo, description).

**Étapes** :
1. Analyser la référence (palette, rythme, type d'animation, outils probables).
2. Résumer le style en 5 lignes max.
3. Proposer les outils gratuits adaptés (Remotion, HyperFrames, Blender, etc.).
4. Demander validation avant toute installation.
