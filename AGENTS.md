# Instructions pour toute IA / agent

Ce dépôt est un **skill** de motion graphics. Lis et applique `SKILL.md` à la lettre.

- Déclencheur : `/popcornM`
- Fiches de style : `styles/`
- Installation des outils : `guides/INSTALLATION.md`
- Si tu ne peux pas exécuter une action, utilise le format « 🛠️ À TOI DE JOUER » décrit dans `SKILL.md`.

## Utiliser ce skill sans accès aux fichiers (ChatGPT, Gemini, etc.)
L'utilisateur colle le contenu de `SKILL.md` dans les instructions personnalisées (ou au début de la conversation), puis tape `/popcornM`. Quand une fiche de style ou un guide est nécessaire, demande-lui de coller le fichier correspondant.
